🔵 공문서 교정 모드
🔤
한국어 맞춤법·어법 AI 검증
맞춤법·띄어쓰기 오류 / 경어체·평서체 혼용 / 공문서 표준 용어 준수 / 자주 틀리는 표현 전수 검토 (예: 재고→제고, 수랍→수립)
📅
날짜·요일 정확성 AI 검증
날짜와 요일의 정확한 매칭 (Python datetime으로 계산) / 존재하지 않는 날짜 탐지 (예: 2월 30일) / 현재·과거·별첨 섹션별 구분 표시
🔡
단어 누락·반복·비정상 표현 AI 검증
문맥상 필수 단어 누락 / 불필요한 단어 중복 / 오타로 의미 불명확한 단어 / 본문과 붙임 항목 간 표현 불일치
🟣
행사명·기관명 전체 정합성 AI 검증
문서 앞뒤에서 동일 행사·기관·프로그램이 다른 이름으로 혼용되는지 전체 텍스트 대상으로 탐지 (예: "장애학생 인권보호한마당" ↔ "인권한마당")
🔶
암묵지 항목 탐지 사용자 확인
AI가 정답을 알 수 없는 기관 고유 정보를 탐지 후 확인 요청 — 발신 기관명 / 공문번호 형식·연번 / 담당자 이름 / 담당자 연락처(전화·이메일) / 수신기관 명칭
🟠 연도변경 분석 모드 추가 항목
🔴
기존 문서 자체 오류 AI 검증
원본 문서에서 이미 틀린 날짜·요일·연도 표기 탐지
🟠
연도 필수 변경 항목 AI 검증
제목·본문·별첨의 연도 표기 중 반드시 바꿔야 하는 항목 전체 목록 제시
🟡
날짜 전면 재설정 필요 항목 AI 검증
행사일·신청 기간·제출 기한 등 연도만 바꿔서는 안 되고 날짜 자체를 새로 지정해야 하는 항목
🟢
내용 갱신 필요 항목 사용자 확인
인사 이동·예산 변경·전년도 실적·근거 법령 개정 등 사람만 알 수 있는 내용 갱신 항목 안내
🟣
명칭 불일치 탐지 AI 검증
연도 표기 혼용 / 축약·오탈자 혼용 / 기관명 혼용을 문서 전체에서 그룹별로 탐지
🔵

📋

사용 방법

어떤 AI에서든 사용 가능합니다

1
ZIP 다운로드 & 압축 해제
아래 버튼을 눌러 ZIP 파일을 다운로드하고 압축을 해제합니다.
⬇ ZIP 다운로드
2
스킬 폴더에 복사
압축 해제된 폴더를 아래 경로로 이동합니다.
C:\Users\사용자명\.claude\skills\korean-official-doc-analyzer
3
Claude Desktop 재시작
완전히 종료 후 재시작하면 스킬이 자동 인식됩니다. 이후 업데이트는 아래 명령어 한 줄로 가능합니다.
cd "...\.claude\skills\korean-official-doc-analyzer"
git pull
💡 사용법: 설치 후 Claude에게 공문서 파일을 올리고 "공문 검토해줘" 또는 "작년 계획서 분석해줘"라고 입력하면 자동으로 실행됩니다.
⚡ 가장 쉬운 방법
ChatGPT 채팅창에 SKILL.md 파일과 분석할 공문서 파일을 함께 올리고
"공문 검토해줘" 또는 "작년 계획서 분석해줘" 라고 입력하면 바로 실행됩니다.
⬇ ZIP 다운로드 (SKILL.md 포함) 압축 해제 후 SKILL.md 파일을 채팅창에 드래그앤드롭
1
SKILL.md 파일 준비
ZIP을 다운로드하고 압축을 해제하면 SKILL.md 파일이 있습니다.
🐙 GitHub에서 보기
2
ChatGPT 채팅창에 업로드
ChatGPT 새 대화에서 SKILL.md 파일과 공문서 파일을 함께 첨부합니다.
파일 첨부: SKILL.md + 공문서 파일
입력: "공문 검토해줘"
3
바로 실행
추가 설정 없이 바로 분석이 시작됩니다. 다음 번에도 같은 방식으로 사용하면 됩니다.
